
# SmartClass AI: Платформа видеоаналитики и безопасности учебного пространства

Локальная мультимодальная система анализа вовлеченности учащихся, педагогического автоаудита и контроля безопасности в классах.

## Архитектура решения
* **Head Pose & Attention Tracking:** оценка наклона головы и зоны внимания (OpenCV, MediaPipe).
* **Device Detection:** детекция использования смартфонов под партами (YOLOv8 Nano, ONNX Runtime).
* **Audio Analysis & Timing:** транскрибация и хронометраж баланса монолог/интерактив (OpenAI Whisper).
* **Watchdog Security Mode:** трекинг аномальной активности (потасовки, падения) в проходах во время отсутствия педагога.
* **Privacy by Design:** вычисления на стороне клиента (Edge), отсутствие видеоархива, полное соответствие 152-ФЗ.

## Стек технологий
Python 3.11, FastAPI, OpenCV, MediaPipe, Ultralytics YOLOv8, Whisper, React / TailwindCSS.
